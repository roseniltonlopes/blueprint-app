# Código-fonte das pranchas (canvas v2)

Backup versionado das 8 pranchas do canvas editável do Blueprint:

https://claude.ai/artifact/Cae8a8KKv5bRKpx234Zh3h

| Arquivo | Tela |
| :--- | :--- |
| `Main.dc.html` | Cadastro e login |
| `Home-vazio.dc.html` | Home, estado inicial |
| `Home-ativa.dc.html` | Home, categoria ativa |
| `Home-outro.dc.html` | Home, opção Outro |
| `Home-escuro.dc.html` | Home, após registrar (modo escuro) |
| `Calendario-escuro.dc.html` | Calendário (modo escuro) |
| `Historico.dc.html` | Histórico |
| `Perfil-escuro.dc.html` | Perfil (modo escuro) |
| `canvas.json` | Posição e título de cada prancha |

- A **edição** é feita no link do canvas. Estes arquivos servem de backup e histórico.
- Eles dependem do `support.js` do editor do canvas e **não abrem sozinhos** em um navegador.
- Os valores de cor, tipografia e movimento estão em [`../../04-design-tokens-e-motion.md`](../../04-design-tokens-e-motion.md).
